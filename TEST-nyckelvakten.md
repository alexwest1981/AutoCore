# Test av nyckelvakten, andra provet

Den här filen finns bara för att kunna öppna en pull request och prova att automationen skriver en
kommentar när PR:en saknar uppgiftsnyckel. Filen ligger på en tillfällig gren, PR:en stängs utan att
mergas, grenen tas bort, och kommentaren tas bort efteråt. Ingenting hamnar i `develop`.
